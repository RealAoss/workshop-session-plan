# Workshop Session Plan

Publish a one-page workshop plan with activities and observable outcomes.

Open `index.html` in a modern browser. Edit the sample inputs to update the result, then print or download it. Processing stays in the tab.

## Example

Replace the example entries with your own details. Blank sections are omitted from the exported document. Print the result or download it as plain text. Entries remain in the tab until it closes.

## Limitations

The form keeps entries in the open tab. Review the generated document and download or print it before closing the window.
